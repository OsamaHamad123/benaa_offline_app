| Widget        | الوصف                                                            |
| ------------- | ---------------------------------------------------------------- |
| `_EmptyState` | عرض حالة فراغ موحّد (أيقونة + رسالة + action اختياري)            |
| `_ErrorState` | عرض حالة خطأ موحّد (أيقونة error + رسالة)                        |
| `_StatusChip` | chip صغير يعرض الحالة مع ترجمة عربية وألوان متناسقة مع الـ theme |
| `_kvRow()`    | helper function لعرض زوج (key: value) بتنسيق موحّد               |
