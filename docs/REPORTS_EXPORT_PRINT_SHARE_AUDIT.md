## الإصلاحات المُطبَّقة

### 1. ترجمة PDF إلى العربية (`beneficiaries_export_service.dart`)

| قبل                                    | بعد                                   |
| -------------------------------------- | ------------------------------------- |
| `'Beneficiaries Comprehensive Report'` | `'تقرير المستفيدين الشامل'`           |
| `'Date: ...'`                          | `'التاريخ: ...'`                      |
| `'Total'`                              | `'الإجمالي'`                          |
| `'Synced'`                             | `'مزامن'`                             |
| `'Pending'`                            | `'معلق'`                              |
| `'Beneficiaries List'`                 | `'قائمة المستفيدين'`                  |
| `'Full Name'`                          | `'الاسم الكامل'`                      |
| `'National ID'`                        | `'الرقم الوطني'`                      |
| `'Phone'`                              | `'الهاتف'`                            |
| `'Sync Status'`                        | `'حالة المزامنة'`                     |
| `'Generated by Benaa System - ...'`    | `'تم الإنشاء بواسطة نظام بناء - ...'` |

> **ملاحظة:** خط عربي في PDF يتطلب `pw.Font.ttf(...)` من assets. حالياً النصوص تُعرض لكن قد لا تظهر بخط عربي حقيقي في الـ PDF renderer — خطوة مستقبلية: إضافة `assets/fonts/NotoNaskhArabic.ttf` وتسجيله في `pubspec.yaml`.

### 2. إضافة Share لـ `beneficiaries_report_page.dart`

- استُورد `package:share_plus/share_plus.dart`
- أضفنا دالة `_shareFile(filePath, mimeType)`
- عدّلنا `_exportToExcel()` و`_exportToPdf()` لقبول `{bool share = false}`
- أضفنا في `PopupMenuButton`: خياري "مشاركة Excel" و"مشاركة PDF"
- عند share: يصدّر الملف ثم يستدعي `Share.shareXFiles([XFile(filePath)])`
